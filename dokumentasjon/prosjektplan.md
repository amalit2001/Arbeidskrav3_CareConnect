# Prosjektplan – CareConnect

## Mål
Målet er å analysere hvordan CareConnect kan utvikles som et objektorientert system med fokus på sikkerhet, GDPR/personvern og universell utforming.

## Arbeidsmetode
Jeg bruker en enkel smidig arbeidsmetode med Kanban i GitHub Projects. Arbeidet deles inn i mindre oppgaver som flyttes mellom Backlog, To do, In progress, Review og Done.

## Leveranser
- Fagrapport på 2000–3000 ord
- UML-klassediagram
- Kodeeksempel i Python
- Kort dokumentasjon av krav og designvalg
- Referanseliste etter APA 7
