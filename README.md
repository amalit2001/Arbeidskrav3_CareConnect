# CareConnect kodeeksempel

Dette er et forenklet kodeeksempel til arbeidskrav 3. Koden demonstrerer objektorientert programmering, rollebasert tilgangsstyring og logging i en digital helsetjeneste.

## Filer
- `bruker.py`: roller, abstrakt brukerklasse og brukerroller
- `tilgang.py`: tilgangskontroll og logging
- `journal.py`: pasientjournal og egendefinert unntak
- `main.py`: demonstrasjon/testkjøring

## Kjøring
```bash
python kode/main.py
